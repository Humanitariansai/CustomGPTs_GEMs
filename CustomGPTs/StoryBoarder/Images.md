# Images — Reference Notes

## Usage
When the user runs `describe`, analyze uploaded images and output:
1) One 2–3 sentence **subject-only** paragraph per image (include visible **movement**).
2) Append the **macro tail** exactly:
   `{style} {srefs} --ar {aspect} --p {pcodes}`

- IMG_002: Overhead of desk; map, polaroids, pinned thread lines; hand enters frame.
- IMG_003: Alley at dusk; figure pauses; neon reflection ripples in puddle.
